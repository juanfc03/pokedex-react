# Pokédex React

Una Pokédex hecha con React y Vite.

## Stack

| Herramienta  | Versión |
| ------------ | ------- |
| pnpm         | 11.20.0 |
| Node.js      | v26.7.0 |
| React        | ^19.2.8 |
| React Router | ^8.3.0  |
| Vite         | ^8.2.0  |

## Instalar y correr

```sh
pnpm install
pnpm dev
```

## Scripts

| Comando       | Descripción            |
| ------------- | ---------------------- |
| `pnpm dev`    | Servidor de desarrollo |
| `pnpm build`  | Compilar para prod     |
| `pnpm lint`   | Revisar con ESLint     |
| `pnpm preview`| Previsualizar build    |
